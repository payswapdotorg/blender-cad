## 1. Isolation rules (binding for every experiment here)

1. **Nothing in this directory is product code.** No import from `experiments/` may appear
   in `modules/`, `scripts/`, `tests/` (repo root), or the extension build. Nothing here
   changes the shipped extension, the document schema (`bcdoc` stays authoritative),
   the kernel direction (ADR-0002), the CAD tool contract, packaging or the release manifest.
2. **The upstream repository is never vendored into git — and neither are the solver wheels.**
   `fetch-upstream.sh` materializes the pinned tag into `.upstream/` (gitignored) and
   `fetch-solver.sh` verifies the pinned wheel; committed evidence records the SHAs and
   digests. The clone and any unpacked wheel are reproducible from the scripts.
3. **No production runtime dependency may be introduced as a side effect.** Any venv,
   `--target` install dir or Blender user-scripts dir created here lives outside this
   tree (default: `/home/z/cad-sketcher-eval-scratch/`) and is never committed; the
   pinned Blender runtime's own site-packages is never polluted permanently.
4. **Fixtures carry provenance.** Self-authored fixtures state author + date; anything
   derived from upstream files (a saved `.blend`, a serialized sketch, quoted license
   text) records the source path and the pinned SHA/tag it was taken from.
5. **Results are machine-readable and committed** (`results/*.json`), generated by the
   scripts/drivers in this tree, never hand-edited. Each result file embeds the exact
   command, the upstream tag/SHA, timestamps and environment facts (mirroring the TL2
   SolidCraft result schema).
6. **Failures are recorded, never silently dropped.** An experiment that cannot complete
   records its blocker in its result JSON and in the findings doc — an import failure or
   an incompatibility is a finding, not a task failure.

## 5. Evidence provenance

Every committed result records, at minimum: the upstream repo + tag + commit SHA, the
harness commit, the exact command line, wall-clock timestamps, host facts (CPU count,
memory), and the raw outputs (exit codes, stdout of the probes). License quotes in
`findings/` carry file paths (+ line numbers where stable) and the tag/SHA they were
read from. See `findings/license-supply-chain.md` §7 for the verification-log format
(`license-inventory.md` §7 protocol).
