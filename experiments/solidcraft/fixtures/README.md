# Fixtures — shared, provenance-recorded

Every fixture set lands in its own subdirectory with a README stating:

- author + date (self-authored), or upstream source path + pinned SHA (derived),
- license (self-authored = repo license; upstream-derived = `MIT OR Apache-2.0`,
  attribution preserved per upstream NOTICE/ATTRIBUTION),
- the consuming experiments.

No fixture may be generated by a tool whose output we cannot redistribute.
